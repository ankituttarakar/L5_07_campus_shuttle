# Static Code Analysis & Functional Bug Identification Report

This document records the issues identified in `shuttle_system.py` through automated static code analysis (Pylint 4.1.3, Flake8 7.4.1, Bandit 1.9.4) and manual code inspection / dynamic execution.

## Issues Table

| Issue | Type | Line(s) | Description | Fix Approach |
|---|---|---|---|---|
| **Unhandled KeyError on Removed Route Calculation** | Correctness (Runtime Crash) — *Manual Discovery* | 55, 58 | Line 55 deletes route `"R3"` via `remove_route("R3")`. Line 58 then calls `average_load("R3")`, which accesses `routes["R3"]` and crashes with an unhandled `KeyError`. Static analysis tools do not detect this runtime sequence. | Update `average_load()` to validate route existence and return `None` or raise a descriptive error; safeguard the lookup in `main()` with existence verification or safe handling so the program does not crash. |
| **Unvalidated Route Lookup from User Input** | Correctness (Runtime Crash) — *Manual Discovery* | 56–57 | `input()` prompt allows users to specify an arbitrary route ID. Looking up `routes[choice]["trips"]` without checking if `choice` exists crashes with `KeyError` when given unknown routes (e.g., `"R99"`). Static analysis tools cannot infer user input domains. | Validate `choice` against `routes.keys()` before dictionary lookup, displaying a user-friendly error message if the route is not found. |
| **Silent Exception Suppression via Bare `except`** | Security / Correctness — *Bandit (B110), Pylint (W0702), Flake8 (E722)* | 29–30 | `underused_routes()` uses a bare `except: pass` block. This anti-pattern silently suppresses all exceptions (including `TypeError`, `ZeroDivisionError`, `KeyError`, and even system signals like `KeyboardInterrupt`), hiding defects and masking bad passenger data. | Remove the bare `except: pass`. Replace with targeted checks (e.g., verifying route existence and non-empty trip list) and handle only specific expected exceptions with appropriate logging. |
| **ZeroDivisionError on Empty Route Trips** | Correctness — *Manual Discovery* | 20–21 | In `average_load()`, `sum(trips) / len(trips)` divides by zero if a route has no recorded trips (`len(trips) == 0`), throwing an unhandled `ZeroDivisionError`. Static analysis tools do not track list contents. | Check `if not trips:` before computing the division; return `0.0` (or `None`) when no trips are recorded. |
| **Dangerous Mutable Default Argument** | Correctness / Maintainability — *Pylint (W0102)* | 11 | `add_trip_log` defines `logs=[]` as a default parameter. In Python, default arguments are evaluated once at function definition time. Subsequent calls mutate the same shared list, causing trip logs to accumulate across unrelated calls. | Change default parameter to `logs=None` and initialize `logs = []` inside the function body if `logs is None`. |
| **Invalid Passenger Counts Accepted (Negative & Non-Integer Data)** | Correctness / Data Integrity — *Manual Discovery* | 12, 49–50 | `add_trip_log()` blindly appends `passenger_count` without validation. Line 49 appends `-6` (impossible negative passenger count) and line 50 appends `"full"` (string), which later breaks mathematical operations like `sum(trips)` with a `TypeError`. Dynamic type mismatch was not flagged by Pylint/Flake8/Bandit. | Validate that `passenger_count` is an integer and non-negative (`int` and `>= 0`). Raise `ValueError` or reject invalid inputs with explanatory messages before appending. |
| **Unsafe File Handling and Missing Context Manager** | Correctness / Maintainability — *Pylint (R1732, W1514, W0603)* | 37–44 | `sync_fleet_data()` opens `fleet.json` without `with` statement context managers, risking unclosed file descriptors on error. It also omits explicit UTF-8 character encoding and mutates global state via `global routes`. Path is also relative to CWD. | Use `with open(..., 'w', encoding='utf-8')` and `with open(..., 'r', encoding='utf-8')`. Resolve paths relative to the script directory using `pathlib.Path`, handle `FileNotFoundError` and `json.JSONDecodeError`, and safely return or update fleet data. |
| **Weak PRNG Usage for Driver Assignment** | Security / Maintainability — *Bandit (B311), Pylint (C0103, W0613)* | 33–35 | Bandit flags `random.choice(drivers)` (B311) as standard pseudo-random generator unsuitable for security/cryptography. In addition, Pylint flags `assignDriver` for non-snake_case naming (C0103) and unused argument `route_id` (W0613). | Rename function to `assign_driver` (providing backwards-compatible alias `assignDriver` if needed). Validate `route_id`. Note that `random.choice` is safe for non-cryptographic driver scheduling, or use `secrets.choice` to satisfy strict security requirements. |
| **Module Execution on Import (Missing Entry Point Guard)** | Maintainability / Testability — *Pylint / Flake8 Context* | 60 | `main()` is directly executed at module root without `if __name__ == "__main__":`. Any attempt to import `shuttle_system` in automated tests triggers the interactive input prompt and execution side-effects. | Guard module invocation behind `if __name__ == "__main__":` so functions can be cleanly imported and tested. |
| **Missing Docstrings, Line Length & PEP 8 Style Violations** | Maintainability / Style — *Pylint (C0114, C0116, C0209), Flake8 (E302, E305, E501)* | 1, 11, 13, 16, 19, 23, 33, 37, 45, 60 | Missing module docstring, missing function docstrings, legacy `%` string formatting instead of f-strings, lines exceeding 79 characters, and insufficient blank lines between function definitions. | Add complete PEP 257 docstrings for module and all functions, convert `%` formatting to f-strings, format lines under 79 characters, and ensure proper blank lines. |
